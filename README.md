# Boxing Reminder Bot

Telegram-бот для школы бокса в Батуми (тренер Виктор): напоминает клиенту
о разминке перед персональной тренировкой утверждённым текстом.

MVP-версия: клиенты сами регистрируются, написав боту, а напоминание
тренер/администратор отправляет вручную одной командой по конкретному
клиенту. Автоматической рассылки по расписанию нет — это сознательное
упрощение для старта (см. «Что дальше»).

## Как это работает

1. Клиент открывает бота в Telegram и пишет ему любое сообщение (например,
   своё имя). Бот сохраняет это имя и Telegram-чат клиента у себя локально
   (`clients.json`).
2. Перед тренировкой вы вручную запускаете команду с именем клиента и
   днём/временем тренировки — бот отправляет клиенту утверждённый текст
   напоминания.

**Важное ограничение Telegram:** бот не может первым написать человеку —
клиент обязательно должен сам сначала написать боту хотя бы раз.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
   (`/newbot`, следуйте инструкциям) — получите токен вида
   `123456789:AAExampleTokenValue`.
2. Скопируйте `.env.example` в `.env` и вставьте туда токен:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен
   ```
   `.env` не попадает в git (см. `.gitignore`) — токен нигде не публикуется.

## Запуск

Регистрация клиентов (должен работать постоянно, пока клиенты могут писать боту):
```bash
npm run bot
```

Отправить напоминание конкретному клиенту:
```bash
npm run remind -- "Имя клиента" "суббота, 18:00"
```
Имя должно совпадать с тем, что клиент указал при первом сообщении боту
(регистр не важен). Если клиента ещё нет в списке — команда явно сообщит
об этом и ничего не отправит.

## Данные

- `clients.json` — локальный список «имя клиента → Telegram-чат», создаётся
  автоматически при первой регистрации. Не в git (содержит контакты людей).
- Никаких данных клиентов никуда, кроме Telegram, не отправляется.

## Что дальше (осознанно не реализовано в этой версии)

- Автоматическая отправка по расписанию тренировок — нужен источник
  расписания (таблица/календарь) и решение, за сколько времени до
  тренировки слать напоминание.
- Другие каналы (SMS, WhatsApp) — нужен провайдер и его ключи.
- Хранение клиентов не в JSON-файле, а в БД — если клиентов станет много.
