# Boxing Reminder Bot

Telegram-бот для школы бокса в Батуми (тренер Виктор): напоминает клиенту
о разминке перед персональной тренировкой утверждённым текстом.

Клиенты сами регистрируются, написав боту. Напоминание можно отправить
вручную одной командой по конкретному клиенту, а можно вести файл
`schedule.csv` с расписанием тренировок — тогда бот сам разошлёт
напоминания автоматически, без вашего участия.

## Как это работает

1. Клиент открывает бота в Telegram и пишет ему любое сообщение (например,
   своё имя). Бот сохраняет это имя и Telegram-чат клиента у себя локально
   (`clients.json`).
2. Дальше можно отправить напоминание одним из двух способов:
   - **Вручную** — команда с именем клиента и днём/временем тренировки.
   - **Автоматически** — впишите тренировку в `schedule.csv`, и пока бот
     запущен (`npm run bot`), он сам отправит напоминание за 2 часа до
     тренировки, без вашего участия.

**Важное ограничение Telegram:** бот не может первым написать человеку —
клиент обязательно должен сам сначала написать боту хотя бы раз.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
   (`/newbot`, следуйте инструкциям) — получите токен вида
   `123456789:AAExampleTokenValue`.
2. Скопируйте `.env.example` в `.env` и вставьте туда токен:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен
   ```
   `.env` не попадает в git (см. `.gitignore`) — токен нигде не публикуется.

## Запуск

Бот должен работать постоянно — и для регистрации новых клиентов, и для
автоматических напоминаний по расписанию:
```bash
npm run bot
```

### Автоматические напоминания по расписанию

Создайте в этой же папке файл `schedule.csv` (за образец возьмите
`schedule.example.csv`) с тренировками в формате:
```
Имя,Дата,Время
Иван,15.09.2026,18:00
Лева,16.09.2026,19:00
```
- **Имя** должно точно совпадать с тем, что клиент указал при регистрации
  боту (регистр не важен).
- **Дата** — в формате ДД.ММ.ГГГГ.
- **Время** — в формате ЧЧ:ММ.

Пока запущен `npm run bot`, он сам проверяет этот файл и отправляет
клиенту напоминание за 2 часа до тренировки — без вашего участия. Уже
отправленные напоминания не дублируются (это отслеживается в
`sent-reminders.json`, трогать его руками не нужно).

**Важно:** автонапоминание сработает, только если бот в этот момент
запущен. Если компьютер выключен или `npm run bot` не работает в момент,
когда до тренировки остаётся 2 часа — напоминание не уйдёт.

### Ручная отправка одному клиенту

```bash
npm run remind -- "Имя клиента" "суббота" "18:00"
```
Имя должно совпадать с тем, что клиент указал при первом сообщении боту
(регистр не важен). Если клиента ещё нет в списке — команда явно сообщит
об этом и ничего не отправит.

## Данные

- `clients.json` — локальный список «имя клиента → Telegram-чат», создаётся
  автоматически при первой регистрации. Не в git (содержит контакты людей).
- `schedule.csv` — расписание тренировок, которое вы ведёте сами. Не в git
  (содержит имена и время тренировок).
- `sent-reminders.json` — служебный файл, чтобы не слать одно и то же
  напоминание дважды. Не в git.
- Никаких данных клиентов никуда, кроме Telegram, не отправляется.

## Что дальше (осознанно не реализовано в этой версии)

- Другие каналы (SMS, WhatsApp) — нужен провайдер и его ключи.
- Хранение клиентов и расписания не в файлах, а в БД — если клиентов
  станет много.
- Запуск бота как фоновой службы (чтобы не держать открытым терминал
  вручную) — сейчас `npm run bot` нужно запускать самостоятельно и не
  закрывать окно.
